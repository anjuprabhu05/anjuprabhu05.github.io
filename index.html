01 / FEATURED PROJECT

Know Your Country

An interactive map application: search any country to see its borders highlighted on the map, along with its flag, capital, currency, population and more.

  • Leaflet map that draws each country's border from GeoJSON
  • Node.js + Express REST API with search, autocomplete and ISO-code lookup
  • MySQL database seeded with ~200 countries, borders and key facts
  • Zoneless Angular 20 app built with signals
